# Functional Specification

## System capabilities

The functional baseline contains 2,963 rows: 8 platform capabilities, 7 cross-cutting requirements, 666 module-lifecycle requirements, and 2282 module-feature requirements. Each requirement retains actor, preconditions, trigger, input/evidence, expected output, exceptions, implementation status, source reference, and test mapping in the source register.

## Behavioral specification rule

For each requirement, the clone specification must define: actor, precondition, trigger, processing, state/data change, output, failure behavior, permission, dependencies, and acceptance test. Where the source register cannot establish a value, record `UNKNOWN` or create an `ASSUMPTION`; do not fill the gap with generic ERP behavior.
