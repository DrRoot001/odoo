# Coding Conventions

Preserve the source separation between addon manifests, models/ORM fields, controllers, XML/CSV/JSON data, templates/views, assets, security declarations, migrations, and tests. New clone code must use explicit types/contracts, deterministic migrations, transaction boundaries, structured errors, least-privilege defaults, and source/evidence references.

Exact naming, formatting, lint, and review rules are not fully established by the evidence package and require team-level adoption.
