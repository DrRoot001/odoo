# Technology Stack

## Original Odoo implementation — VERIFIED

Python 3.12+ runtime; Werkzeug/gevent/threaded or prefork service runtime; PostgreSQL through psycopg2 and the ORM/registry; browser JavaScript/TypeScript; XML/QWeb; SCSS/CSS; Python/XML/CSV/JSON/SQL addon data; QWeb/PDF/XLSX reporting; optional LDAP, OAuth, SMTP, Google, payment, storage, IoT, localization, and e-invoicing integrations.

## Cloneable implementation

The clone may use another stack, but must provide equivalent frontend delivery, HTTP/API transport, transactional relational persistence, migrations, background execution, module/extension boundaries, authentication/authorization, reporting/export, file storage, integrations, tests, and observability. Provider choice and deployment topology are `ASSUMPTION` unless separately approved.
