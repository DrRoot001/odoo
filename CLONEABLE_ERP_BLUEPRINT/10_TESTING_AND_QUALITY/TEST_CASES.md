# Test Cases

`Evidence_Test_Case_Register.csv` preserves 3,470 source-derived test cases with source file, module, layer, objective evidence, and status. Use these as a baseline for clone test design, then add acceptance tests for every requirement and critical cross-module workflow.

Source artifacts are not assumed to pass. Every clone case must record setup data, actor/permissions, trigger, assertions, side effects, failure path, cleanup, and execution evidence.
