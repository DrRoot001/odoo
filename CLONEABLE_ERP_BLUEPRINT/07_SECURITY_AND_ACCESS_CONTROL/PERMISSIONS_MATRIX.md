# Permissions Matrix

The machine-readable registers are the source-derived matrix:

- [`Group_Register.csv`](Group_Register.csv): 192 groups.
- [`Model_Access_Register.csv`](Model_Access_Register.csv): 2,577 model-operation grants.
- [`Record_Rule_Register.csv`](Record_Rule_Register.csv): 11 record filters.
- [`Route_Security_Register.csv`](Route_Security_Register.csv): 669 route policies.

A complete effective matrix is not statically provable because installed modules, implied groups, user assignments, and runtime domains affect results.
