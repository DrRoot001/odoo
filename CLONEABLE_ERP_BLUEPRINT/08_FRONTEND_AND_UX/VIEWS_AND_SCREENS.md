# Views and Screens

The source evidence contains 3,962 view records, 6,998 action/menu records, 884 menu declarations, 2,247 templates, and 33,992 XML records. Screen implementation must resolve model/action/view relationships, inherited XML, group visibility, route context, and asset dependencies.

Use the generated registers for source paths and declarations; final screen behavior requires an installed registry and browser/rendering validation.
