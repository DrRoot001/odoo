# UI Components

The component register preserves 1,818 frontend component/class evidence rows, 1,839 registry files, 139 service-registration files, and 121 client route/router files. Implement reusable components with explicit inputs/outputs, lifecycle, service dependencies, loading/error/empty states, permissions, and test hooks.

A source class or registry match is evidence of an artifact, not proof of a visible screen or successful runtime registration.
