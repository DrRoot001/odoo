# Assumptions and Gaps

Open gaps are drawn from the audit register: installed modules/runtime schema; production topology, HA, backup/RPO/RTO/monitoring; executed test and coverage results; complete API payload contracts; resolved UI inheritance/assets; technical-debt reachability; safe-evaluation and optional integration security review; and restore rehearsal.

Every gap is classified as `UNKNOWN`, `Requires runtime verification`, `Not Found in Codebase`, or an explicit clone design `ASSUMPTION`. No gap is silently converted into a requirement.
