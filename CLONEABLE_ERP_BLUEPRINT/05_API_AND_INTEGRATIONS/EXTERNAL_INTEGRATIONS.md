# External Integrations

The integration inventory contains 204 manifest/integration records. Integration types include authentication providers, mail/SMS, payments, storage, Google services, IoT, localization/e-invoicing, and other optional adapters as recorded in the source inventory.

The clone must isolate provider adapters, protect credentials, define timeouts/retries, expose health and reconciliation, and test provider failure. Activation is deployment configuration, not a guarantee that every integration is enabled.
