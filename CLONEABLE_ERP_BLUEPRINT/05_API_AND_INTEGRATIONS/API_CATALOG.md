# API Catalog

The authoritative controller inventory contains 669 route declarations across 117 modules. It is the source endpoint catalog for the clone baseline. The broader route discovery inventory is not used as the authoritative endpoint count.

| Request type | Count |
|---|---:|
| `jsonrpc` | 216 |
| `http` | 446 |
| `json2` | 7 |


Every endpoint must receive a clone API contract with purpose, actor, authentication, authorization, request parameters/body, response, errors, validation, idempotency, rate limits, retries, audit, and database effects. Unknown payloads remain `UNKNOWN`.
