# Environment Configuration

`Configuration_Option_Register.csv` preserves 75 source configuration options and `Environment_Variable_Register.csv` preserves 72 environment-variable references. Treat option names, destinations, types, defaults, and secret status as source evidence; validate effective values in each environment.

Separate development, test, staging, and production configuration; validate database filters, proxy/TLS settings, workers/limits, logging, mail, test flags, addon paths, and credentials before startup.
