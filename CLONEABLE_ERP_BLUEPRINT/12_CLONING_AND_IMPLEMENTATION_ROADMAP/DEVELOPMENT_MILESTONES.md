# Development Milestones

| Milestone | Exit condition |
|---|---|
| M0 Evidence baseline | Blueprint registers and source evidence are versioned and reconciled. |
| M1 Platform skeleton | Application starts, authenticates, persists data, migrates, logs, and exposes health checks. |
| M2 Security/tenancy | Roles, ACLs, record rules, company isolation, and denied-path tests work. |
| M3 MVP flow | Lead/customer, quotation/order, fulfillment, invoice/payment, and core reporting pass acceptance. |
| M4 Domain expansion | Selected purchase, accounting, HR, project, manufacturing, POS, ecommerce, website, and marketing slices pass gates. |
| M5 Parity release | Feature parity register reviewed; remaining gaps are accepted, deferred, or implemented with evidence. |
| M6 Production readiness | Deployment, backup/restore drill, monitoring, performance, security, migration, and rollback gates pass. |
