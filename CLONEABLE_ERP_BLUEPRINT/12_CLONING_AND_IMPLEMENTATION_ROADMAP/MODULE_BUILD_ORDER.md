# Module Build Order

Build dependency foundations before domain consumers: core/base and metadata; users/groups/security; contacts/companies; products/catalog; CRM; sales; inventory; purchase; accounting/invoicing/payments; projects; HR/payroll; manufacturing; POS; ecommerce/website; marketing; localization/provider integrations; and remaining optional modules.

This is a clone implementation recommendation (`INFERRED` from module dependencies and workflows), not a claim that the source installs modules in this single sequence. Use the 666-module coverage register and each module README for exact prerequisites.
