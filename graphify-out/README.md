# Graphify output for ERP SYSTEM

This directory is a committed, deterministic Graphify-compatible knowledge graph generated from the repository evidence package. It is intentionally compact relative to the 50,889-file source repository and is designed for AI navigation.

## Files

- `graph.json` — machine-readable nodes and EXTRACTED relationships.
- `GRAPH_REPORT.md` — inventory, evidence boundary, and high-connectivity modules.
- `ai-index.md` — token-efficient traversal instructions and query recipes.
- `graph.mmd` — high-level Mermaid map.

To regenerate/enrich with the upstream Graphify CLI, install `graphifyy` and run `graphify install`, then use `/graphify .` or `/graphify CLONEABLE_ERP_BLUEPRINT --update`. Do not commit credentials, caches, or provider responses.
