# UI/UX Traceability — Phase 9

| UI surface | Evidence inventory | Runtime verification |
|---|---|---|
| Backend views | `View_Inventory.csv` | Resolve inherited XML views and user-group visibility |
| Menus/navigation | `Menu_Inventory.csv` | Load menu tree for selected modules/user |
| Actions | `Action_Inventory.csv` | Resolve action targets and view modes |
| Website/QWeb templates | `Template_Inventory.csv` | Render template inheritance and route context |
| Frontend components | `Frontend_Component_Inventory.csv` | Execute browser/client lifecycle |
| Services/registries | `Frontend_Service_Inventory.csv`, `Frontend_Registry_Inventory.csv` | Resolve bundle/runtime registration |
| Styles/assets | `Style_Asset_Inventory.csv`, `Asset_Declaration_Inventory.csv` | Build bundles and inspect responsive/accessibility output |
