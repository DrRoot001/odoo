# Functional Requirements

The complete Phase 3 functional requirements specification is maintained in [`Functional_Requirements_Document.md`](Functional_Requirements_Document.md), with the machine-readable register in [`Functional_Requirements.csv`](Functional_Requirements.csv).

Requirements are grouped into platform, module, feature-facet, validation, business-rule, security, operations, and reporting families. Each requirement is linked to source evidence and explicitly distinguishes static implementation evidence from runtime verification.
