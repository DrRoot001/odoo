# Phase 4 Module Detail Methodology

Each of the 666 module pages follows the same evidence-based structure:

1. Overview and manifest identity.
2. Module structure and artifact counts.
3. Actors and permissions, limited to evidence actually present.
4. Functionalities by model, API, UI/data, security, scheduled/automation, reporting, and test artifacts.
5. Screens/UI evidence from XML identifiers, menus, templates, views, and browser assets.
6. Business workflow entry points and explicit runtime-verification boundaries.
7. Database/model declarations and schema limitations.
8. Controller/API evidence and route-level verification limits.
9. Declared dependencies and extension relationships.
10. Implementation assessment and complete source inventory.

The machine-readable aggregate is `Module_Detail_Index.csv`; the complete repository file inventory remains `01_CODEBASE_ANALYSIS/Repository_Inventory.csv`.
