## Interpretation
- **Application flags** identify manifests that declare themselves as user-facing applications; extensions and localization modules may contribute substantial behavior without this flag.
- **Artifact counts** indicate implementation surface, not feature quality or runtime enablement.
- **Routes, security files, and tests** are static evidence and require runtime/configuration verification for actual availability.
