## 1. Overview

**Purpose:** Technical tracking of discussion and message-related data

**Manifest description:**

This module extends the mail.message model to enable
technical tracking of discussion-related data.

It captures and stores tracked values generated by
messages and system change operations.
The tracked information can be used for auditing,
debugging, and analysis purposes.

This is especially useful for:
- Investigating technical issues
- Supporting accounting or business process audits
